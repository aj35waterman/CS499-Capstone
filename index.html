Enhancement One: Software Design and Engineering

CS 340 Animal Shelter Dashboard

For my first enhancement, I improved my CS 340 Animal Shelter Dashboard. I separated the application into a dashboard, service layer, and repository layer. I also improved the filtering, chart, map, error handling, and CSV export features.

View Enhancement One Code

Read Enhancement One Narrative

The artifact I selected is CS 340 Animal Shelter Dashboard. Originally I used Python, Dash, MongoDB, Pandas, Plotly, and Dash Leaflet. The dashboard uses animal shelter data from the Austin Animal Center and helps the user search for animals that could possibly be trained for different types of rescue work.

The original application worked, but almost everything was placed inside the same Jupyter Notebook. For my enhancement, I separated the project into three main parts. The dashboard handles what the user sees and clicks. The service layer handles the rescue filters and prepares the data. The repository layer handles the MongoDB connection and database operations.

I also improved the dashboard by adding a record count, replacing the pie chart with a bar chart, improving the map, adding CSV exporting, and removing hard-coded MongoDB credentials.

This enhancement helped me understand how software can be easier to maintain when different responsibilities are separated instead of putting everything in one file.

Enhancement Two: Algorithms and Data Structures

CS 320 Task Scheduler

For my second enhancement, I improved my CS 320 Task Service project by adding priorities, due dates, task dependencies, a dependency graph, PriorityQueue, topological sorting, and cycle detection.

View Enhancement Two Code

Read Enhancement Two Narrative

The artifact I selected for the algorithms and data structures category is my Task Service project from CS 320. The original project used Java, JUnit testing, and a HashMap to store tasks.

I improved the project by adding task priorities, due dates, a dependency graph, a PriorityQueue, topological sorting, and cycle detection.

One of the main things I learned was that priority alone does not create a valid schedule. A task may be important, but it cannot be scheduled if another task has to be completed first.

I also added more JUnit tests for priorities, due dates, dependencies, cycle detection, and deleting dependency references. All 39 tests passed with zero errors and zero failures.

For my database enhancement, I used my CS 340 Animal Shelter Dashboard. The original application already used Python, Dash, and MongoDB.

This enhancement helped me understand how the dashboard, service layer, repository layer, and MongoDB database all work together as one application.
